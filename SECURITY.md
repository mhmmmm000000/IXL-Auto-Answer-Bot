# Security Policy

## Reporting a Vulnerability
If you discover a security vulnerability within this project (such as a way the bot leaks user data or a flaw in the stealth mechanism), please do **NOT** open a public GitHub issue.

Instead, please send an email to the maintainers or reach out via the repository's Discussions tab marked as "Private/Security". 

We will review your report and work with you to address the issue before any public disclosure.

This tool interacts with third-party educational platforms. Users are responsible for ensuring their use of this tool complies with the Terms of Service of those platforms.
